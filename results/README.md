# Saved aggregate results

This directory holds compact outputs from completed local experiments. CSV rates
are fractions unless a field says otherwise; NLL uses natural logarithms. The
files are evidence snapshots, not values regenerated by the current tests.

| Directory | Contents | Reproduction code |
|---|---|---|
| `ply_comparison/` | Absolute/relative move-agreement summaries and paired deltas | `analysis.ply_comparison` |
| `state_probe/` | Probe metrics, cross-replay/drift contrasts and SVG figures | `analysis.state_probe` |
| `time_controls/` | Category agreement, disagreement, macro contrasts and conservative overlap sensitivity | `analysis.time_control_comparison` |
| `decoder_alignment/` | Candidate/baseline agreement tables and bootstrap summary | `analysis.decoder_alignment` |
| `tournaments/` | Consolidated native tournament aggregates and protocol settings | `utils.tournament_runner*` |
| `state_repetition/` | Corpus repetition by ply | `analysis.state_repetition` |
| `training/` | Small original workbook used by the encoder evolution plot | `utils.plots.elo_evolution` |

`manifest.json` records source locations, file sizes and SHA-256 for each saved
snapshot. CSVs/SVGs and the workbook are unchanged copies. Tournament summaries
are consolidated with machine-specific executable paths omitted; each entry
retains its original source hash. The overlap summary retains exposure counts
and confirmed matches while omitting saved machine paths/configuration.

Full prediction CSVs, activation arrays, source selections, SQLite databases,
PGNs, checkpoints and logs remain in their local artifact directories. The
original dated analyses and writing material are retained in `outputs/archive/`.
Do not infer that every saved tournament is a final selected model: its run name,
checkpoint and protocol fields identify the experiment.

Recorded uncertainty is conditional on the original corpus, selected weights
and evaluation protocol. The current source has been reorganized since those
runs; strict resume guards can require a new output directory. Keep original
manifests with full artifacts when reproducing or extending an experiment.
